Nagad Payment Gateway API Reference

নগদ পেমেন্ট গেটওয়ের সকল এন্ডপয়েন্ট, রিকোয়েস্ট হেডার, এনক্রিপ্ট ও সাইন করার নিয়ম, রেসপন্স ফরম্যাট এবং স্ট্যাটাস কোডের পুঙ্খানুপুঙ্খ বিবরণ।

Required HTTP Request Headers

নগদ গেটওয়ের প্রতিটা API রিকোয়েস্টে নিচের হেডারগুলো অবশ্যই পাঠাতে হবে:

Header Key Type Example Value Description
Content-Type string application/json রিকোয়েস্ট বডির ফরম্যাট।
X-KM-Api-Version string v-0.2.0 নগদ API এর ভার্সন।
X-KM-Client-Type string PC_WEB ক্লায়েন্ট টাইপ (e.g. PC_WEB, MOBILE_APP)।
X-KM-IP-V4 string 103.112.54.40 আপনার সার্ভারের পাবলিক IPv4 অ্যাড্রেস।

1 Initialize Payment API

POST /check-out/initialize/{merchantId}/{orderId}

এই API কল করে পেমেন্ট সেশন ইনিশিয়ালাইজ করা হয়। সফল হলে নগদ একটি এনক্রিপ্টেড রেসপন্স দেয় যাতে paymentReferenceId এবং একটি challenge থাকে।

Step A: Plain Sensitive Data (যা এনক্রিপ্ট ও সাইন হবে)

{
    "merchantId": "YOUR_MERCHANT_ID",
    "datetime": "20260929112358",
    "orderId": "ORD20260929052355164",
    "challenge": "8f4abbef61aa8b8a88ba"
}

সতর্কতা: ফিল্ডের নাম অবশ্যই ছোট হাতের "datetime" হতে হবে। orderId অবশ্যই আলফানিউমেরিক (alphanumeric, 5-20 char) হতে হবে।

Step B: Final JSON Request Body

{
    "accountNumber": "017XXXXXXXX",
    "dateTime": "20260929112358",
    "sensitiveData": "Q0X/gAhRr+MD5iC62OwYT0cUm9BVXH6Ff2PRFCrwlzPgJQaAJ5c7Ddeu2YFkeivOj4Fk/F/...",
    "signature": "DqK1RKd+Wce/uoQKTKZa3zL3FResbulzzw8pL5seyHYZo32NpJkamRY1Vb8APfrd5yH6+..."
}

Step C: Decrypted Response Data (কী পাওয়া যাবে)

{
    "paymentReferenceId": "MDkyOTExMjM1ODQ5MS42ODc0ODEyMzc1NjUzOTkuT1JEMjAyNjA5MjkwNTIzNTUxNjQuOGY0YWJiZWY2MWFhOGI4YTg4YmE=",
    "challenge": "8f4abbef61aa8b8a88ba",
    "acceptDateTime": "20260929112358"
}

2 Complete / Place Order API

POST /check-out/complete/{paymentReferenceId}

Initialize API থেকে পাওয়া paymentReferenceId এবং challenge ব্যবহার করে এই API কল করা হয়। সফল হলে নগদ একটি callBackUrl রিটার্ন করে, যাতে কাস্টমারকে রিডাইরেক্ট করে পেমেন্ট পেজে পাঠানো যায়।

Step A: Plain Sensitive Data

{
    "merchantId": "YOUR_MERCHANT_ID",
    "orderId": "ORD20260929052355164",
    "amount": "100.00",
    "currencyCode": "050",
    "challenge": "8f4abbef61aa8b8a88ba"
}

Step B: Final JSON Payload

{
    "sensitiveData": "E93/a82lHI3ogQj91kHDGUv3WBHIPuQuo9AOtoQygCojytj+iGGTkQMa+8QYNvK3bS+vkKq13...",
    "signature": "VPO4heyWfTOTD2tHGyRwuEtozsSyCvsVI7RfIbDqO4j0sf6a5Ja8QAXdj1FxTMKgJi9H4ZhH...",
    "merchantCallbackURL": "https://yourdomain.com/api/nagad/callback",
    "additionalMerchantInfo": {
        "customerName": "Shakhawat Hossain",
        "productName": "Software License",
        "invoiceId": "INV-1002"
    }
}

Step C: Response Format

{
    "callBackUrl": "https://api.mynagad.com/api/dfs/check-out/redirect-gateway?id=MDkyOTExMjM1OD..."
}

3 Callback Handling & Security Rules

GET {merchantCallbackURL} 
GET /api/nagad/callback?merchant=YOUR_MERCHANT_ID&order_id=ORD20260929052355164&payment_ref_id=MDkyOTExMjM1OD...&status=Success&status_code=00_000_00 HTTP/1.1
গুরুত্বপূর্ণ সিকিউরিটি রুল:

কলব্যাক পাওয়া মানেই পেমেন্ট কনফার্ম নয়! কলব্যাকের ডাটা ম্যানিপুলেট করা সম্ভব। তাই কলব্যাকে পাওয়া payment_ref_id দিয়ে অবশ্যই Verify Payment API কল করে সার্ভার-টু-সার্ভার যাচাই করার পর অর্ডার PAID করতে হবে।

Nagad Error Code Dictionary

Error Code Meaning Cause & How to Fix
16_0006_058 Failed to verify signature সিগনেচার মেথডে OPENSSL_ALGO_SHA256 ব্যবহার না করলে অথবা পোর্টালে ভুল পাবলিক কী থাকলে এই এরর আসে।
16_0006_059 Invalid Sensitive Data পেলোডে ফিল্ডের নামে ভুল (যেমন datetime এর জায়গায় dateTime দিলে)।
16_0006_083 Duplicate Order ID একই দিনে একই Order ID দিয়ে দ্বিতীয়বার রিকোয়েস্ট পাঠালে। প্রতিবার ইউনিক Order ID দিতে হবে।
16_0006_068 Invalid Order Id Order ID তে স্পেশাল ক্যারেক্টার (যেমন আন্ডারস্কোর _ বা স্পেস) থাকলে। শুধুমাত্র A-Z, 0-9 হতে হবে।
16_0006_064 Mandatory Header Missing X-KM-Api-Version বা X-KM-IP-V4 হেডার অনুপস্থিত থাকলে।
